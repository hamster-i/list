 ## 📦 Сборка и Запуск (Building)
 
 Выполните следующие шаги, чтобы скомпилировать программу из исходного кода.
 
 ### Шаг 1. Клонирование исходного кода из репозитория
  ```bash
  git clone https://github.com/hamster-i/list
  cd имя-репозитория
  ```
 ### Шаг 2. Подключение заголовочных файлов в проект
  Подключите **заголовочный** файл в ваш проект:
  ```c
  #include <list.h>
  ```
  После подключения заголовочного файла для работы со списком вам доступны интерфейсные функции файла.
 ### Шаг 3. Компиляция
  Если в проекте используется обычный **Makefile**:
  ```bash
  make
  ```
  *(Если вы используете **CMake**, команды будут другими: `cmake -B build && cmake)*
 ### Шаг 4. Запуск программы
  После успешной сборки в папке появится исполняемый файл (например, `main` или `app`):
  ```bash
  ./main --help
  ```
 ### Шаг 5. Очистка временных файлов
  Удалить объектные файлы (`.o`) и бинарники после работы:
  ```bash
  make clean
  ```
